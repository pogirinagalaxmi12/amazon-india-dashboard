# 📊 Amazon India Sales Dashboard

## 📌 Project Overview

The Amazon India Sales Dashboard is a data analytics project designed to analyze sales performance and transform raw sales data into meaningful business insights.

This project focuses on identifying sales trends, evaluating product performance, monitoring key performance indicators (KPIs), and supporting data-driven business decisions through interactive visualizations.
## 🎯 Project Objectives

- Analyze overall sales performance.
- Identify top-performing products and categories.
- Track sales trends over time.
- Monitor key performance indicators (KPIs).
- Understand product and category performance.
- Generate actionable business insights.
## 🛠️ Tools & Technologies

- Microsoft Excel
- Data Cleaning and Data Preparation
- Pivot Tables
- Pivot Charts
- Interactive Dashboard Design
- Data Visualization
## 📈 Key Performance Indicators (KPIs)

The dashboard can include the following metrics, depending on the available dataset:

- Total Sales
- Total Orders
- Total Quantity Sold
- Average Order Value
- Best-Performing Products
- Category-Wise Sales Performance

## 📊 Dashboard Features

- Sales performance overview
- Product-wise sales analysis
- Category-wise sales distribution
- Sales trend analysis
- KPI summary cards
- Interactive charts and visualizations

## 💡 Business Value

This project demonstrates how data analytics and visualization can help businesses:

- Identify sales trends and patterns.
- Understand product performance.
- Monitor important business metrics.
- Make informed, data-driven decisions.
- Discover opportunities to improve sales performance.
