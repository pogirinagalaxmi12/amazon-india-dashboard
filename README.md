#📊 Amazon India Sales Dashboard
📌 Project Overview

The Amazon India Sales Dashboard is a data analytics project designed to analyze sales performance and transform raw data into meaningful business insights. It provides an overview of sales trends, product performance, and key business metrics to support data-driven decision-making.

#🎯 Project Objectives
Analyze overall sales performance.
Identify top-performing products and categories.
Track sales trends and patterns.
Monitor key performance indicators (KPIs).
Generate actionable business insights.
